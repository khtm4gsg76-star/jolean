Admin password-only login checks
================================
1. Python syntax compile: app.py and all project Python files.
2. JavaScript syntax check: inline scripts from login.html.
3. HTML structure: required admin-only login IDs exist and are unique.
4. Source database password hash: SHA-256 candidate matches bundled admin record.
5. Backend source checks: route exists, password validation is server-side, rate limiting exists, successful login creates the admin session, and the first recovery sets a persistent database flag.
6. Archive integrity: all ZIP members can be read.

A live Railway login test was not possible because this environment has no access to the user's Railway deployment or its mounted /data volume.
